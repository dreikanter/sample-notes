# sample-notes

A sample notes store for testing
[notes-cli](https://github.com/dreikanter/notes-cli),
[notes-view](https://github.com/dreikanter/notes-view), and
[notes-pub](https://github.com/dreikanter/notes-pub).

Filename format expected by `notes-cli`:
`YYYYMMDD_ID[_slug][.TYPE].md`, where `TYPE` is one of
`todo`, `backlog`, `weekly`.

## Content

All notes in this store were generated by an LLM (Claude — a mix of
Opus, Sonnet, and Haiku). Dates are spread across a three-year window
ending in early 2026. About half the notes carry YAML frontmatter
(title, tags, optional `public: true`), the rest are plain markdown.
Some notes include external links (Wikipedia, docs sites, etc.) and
cross-references to other notes in the store via `[[YYYYMMDD_ID]]`
wiki-style links.
