# SQLite quick reference

A running reference for SQLite CLI usage and common query patterns. I keep a terminal tab open with this beside whatever project I'm working on.

## Opening and basics

```
sqlite3 mydb.db        # open or create
.tables                # list tables
.schema tablename      # show CREATE statement
.mode column           # aligned output
.headers on            # show column names
.quit
```

## Useful pragmas

```sql
PRAGMA journal_mode = WAL;   -- better concurrency
PRAGMA foreign_keys = ON;    -- not enabled by default
PRAGMA table_info(tablename);
```

## Importing CSV

```
.mode csv
.import data.csv target_table
```

For large files, wrap in a transaction — it's dramatically faster. Without one, SQLite commits after each row.

## JSON functions (3.38+)

```sql
SELECT json_extract(payload, '$.user.id') FROM events;
SELECT * FROM events WHERE json_each.value = 'error'
  JOIN json_each(payload, '$.tags');
```

## Full-text search (FTS5)

```sql
CREATE VIRTUAL TABLE docs USING fts5(title, body);
INSERT INTO docs VALUES('Meeting notes', 'discussed Q4 roadmap...');
SELECT * FROM docs WHERE docs MATCH 'roadmap';
```
