# Tmux quick reference

Personal cheatsheet — I keep forgetting the less common bindings and have to look them up. Default prefix is `Ctrl-b`.

## Session management

| Action | Keys |
|---|---|
| New session | `tmux new -s name` |
| List sessions | `tmux ls` or `prefix + s` |
| Attach to session | `tmux attach -t name` |
| Rename session | `prefix + $` |
| Detach | `prefix + d` |
| Kill session | `tmux kill-session -t name` |

## Windows (tabs)

| Action | Keys |
|---|---|
| New window | `prefix + c` |
| Next / prev window | `prefix + n` / `prefix + p` |
| Go to window by number | `prefix + 0–9` |
| Rename window | `prefix + ,` |
| Close window | `prefix + &` |
| List windows | `prefix + w` |

## Panes

| Action | Keys |
|---|---|
| Split horizontal | `prefix + "` |
| Split vertical | `prefix + %` |
| Move between panes | `prefix + arrow keys` |
| Swap pane | `prefix + {` or `prefix + }` |
| Zoom pane (toggle fullscreen) | `prefix + z` |
| Resize pane | `prefix + Ctrl-arrow` |
| Kill pane | `prefix + x` |

## Copy mode

`prefix + [` enters copy mode. Navigate with vim keys if you set `setw -g mode-keys vi`. Space to start selection, Enter to copy. `prefix + ]` to paste.

## Config snippets I actually use

```
set -g mouse on
set -g history-limit 50000
setw -g mode-keys vi
set -g base-index 1
```

The mouse option saves me constantly. Setting `base-index 1` means windows number from 1, which aligns with the keyboard layout.

Full manual: [tmux wiki](https://github.com/tmux/tmux/wiki)
