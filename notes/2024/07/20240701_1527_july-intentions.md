# July intentions

July feels like the real start of summer now that June's been put to bed. A few specific things I want to lean into.

**Work**

The API rate-limit spec needs to be done by the 5th. Beyond that, I'm trying to protect Thursday afternoons for uninterrupted technical work — I've been too meeting-heavy lately and it shows in the quality of my code review.

**Learning**

I want to finish the distributed systems course I started on [MIT OpenCourseWare](https://ocw.mit.edu/). Six lectures left. The consensus protocols section is the part I've been dreading because my mental model of Raft is still shaky. That's exactly why I need to do it.

**Physical**

Swim twice a week. The lido is open and I keep saying I'll go. This month I actually go.

**Creative**

One long-form piece of writing. Not a note, not a log — something with an argument. I haven't written anything properly shaped since March.

**Social**

I owe at least four people a proper response or catch-up. Not texts. Actual sit-down time.

**What I'm not doing**

Starting any new projects in July. I have a list of interesting side project ideas that will wait until August. The backlog grows by itself — it doesn't need encouragement.
