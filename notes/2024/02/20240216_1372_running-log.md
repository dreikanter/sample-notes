# Running log — February

Starting to track this properly since the 5k is now a commitment.

## Current state

- Comfortable distance: 2.5–3km before the effort feels unsustainable
- Average pace: 6:30/km (slow but consistent)
- Running days per week: 3 (Tuesday, Thursday, Saturday)
- Surface: road, mostly flat route through the park

## Goal

Comfortable 5k by April 7. "Comfortable" means I can finish without walking and not feel destroyed afterward. Not trying to set a time.

## This week's runs

**Tuesday (2/13):** 3km, 6:24/km, felt okay. Cold (4°C), ran with gloves. The first kilometer is always the worst — the urge to stop is strongest when the body is still warming up.

**Thursday (2/15):** 3.5km — added 500m to see how it felt. Felt fine until 3km, then legs started complaining. Pushed through. 6:35/km.

**Saturday (2/17):** Rest day turned training day. Tried 4km. Made it to 3.8km before stopping. Walked the last 200m. This is progress from six weeks ago when 2km was the limit.

## What helps

- Starting slow (consistently ignore this advice the first km)
- The podcast as distraction in the middle km
- Running the same route: not having to make navigation decisions during effort

## Plan

Add 500m per week to the long run. Keep Tuesday and Thursday shorter at 3.5km to build base. By end of March should be able to run 5km continuously.

Reference: [80/20 Running by Matt Fitzgerald](https://www.runnersworld.com/training/) for the philosophy of running most miles easy.
