# Git rebase quick reference

The subset of rebase options I actually use:

- `git rebase main` — replay the current branch on top of `main`.
- `git rebase -i HEAD~5` — interactive; reorder, squash, fixup, edit
  messages.
- `git rebase --onto target upstream branch` — move a range of commits
  onto a different base. Useful when branching off the wrong branch.
- `git rebase --autosquash` — honours `fixup!` and `squash!` commit
  prefixes. Pair with `git commit --fixup <sha>`.
- `git rebase --abort` if something goes sideways, before any
  destructive follow-up.

When to not rebase: anything already shared with other people on a
long-lived branch. Merge instead.

Canonical docs: <https://git-scm.com/docs/git-rebase>
