# ReStructuredText Basics

ReStructuredText (reST) is a lightweight markup language widely used for documentation in the Python ecosystem, particularly with tools like Sphinx. Unlike Markdown's simplicity, reST offers more structural depth and semantic richness, making it well-suited for complex technical documentation projects.

The format uses intuitive syntax: `*emphasis*` for italics, `**strong**` for bold, and backticks for inline code. Sections are marked with underline characters like `====` or `----`. Links follow the pattern `` `text <url>`_ ``, allowing both inline and reference-style citations.

One key advantage over Markdown is reST's directive system, which enables custom content blocks such as code samples, notes, and warnings. The `.. code-block::` directive lets you specify language syntax highlighting, while `.. note::` creates formatted callout boxes. This makes reST particularly valuable for API documentation.

The learning curve is steeper than Markdown, but the investment pays off in larger projects. See the [official ReStructuredText documentation](https://docutils.sourceforge.io/rst.html) for comprehensive syntax details.
