# tmux quick reference

Personal cheatsheet — I keep forgetting the pane-resize bindings and always have to look them up. Prefix is `Ctrl-b` unless noted.

## Sessions

| Action | Keys |
|---|---|
| New session | `tmux new -s name` |
| Attach to session | `tmux attach -t name` |
| List sessions | `tmux ls` |
| Rename session | `prefix $` |
| Detach | `prefix d` |
| Kill session | `tmux kill-session -t name` |

## Windows

| Action | Keys |
|---|---|
| New window | `prefix c` |
| Next / prev | `prefix n` / `prefix p` |
| Go to window N | `prefix N` |
| Rename window | `prefix ,` |
| Close window | `prefix &` |

## Panes

| Action | Keys |
|---|---|
| Split horizontal | `prefix %` |
| Split vertical | `prefix "` |
| Navigate panes | `prefix` + arrow key |
| Resize pane | `prefix Ctrl-arrow` (hold and repeat) |
| Zoom pane | `prefix z` (toggle) |
| Close pane | `prefix x` |
| Show pane numbers | `prefix q` |

## Copy mode

`prefix [` to enter, then navigate with vi keys (if `set-window-option -g mode-keys vi` is set). `Space` to begin selection, `Enter` to copy, `prefix ]` to paste.

## Useful config lines

```
set -g mouse on
set -g base-index 1
set -g history-limit 10000
set-window-option -g mode-keys vi
```

Full option reference: [tmux man page](https://man7.org/linux/man-pages/man1/tmux.1.html). The official wiki at [github.com/tmux/tmux/wiki](https://github.com/tmux/tmux/wiki) has good explanations of the config model.
