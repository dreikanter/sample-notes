# jq reference — filters I actually use

Not a tutorial. Just the patterns I reach for and occasionally forget.

## Basic extraction

```bash
# Get a field
echo '{"name": "Alice", "age": 30}' | jq '.name'
# "Alice"

# Nested field
jq '.user.email' data.json

# Array element
jq '.[0]' data.json

# Array slice
jq '.[2:5]' data.json
```

## Working with arrays

```bash
# Map over array
jq '[.[] | .name]' users.json

# Filter array
jq '[.[] | select(.active == true)]' users.json

# Get unique values
jq '[.[].status] | unique' events.json

# Sort
jq 'sort_by(.created_at)' events.json

# Length
jq 'length' array.json
```

## Reshaping

```bash
# Create new object from fields
jq '{id: .id, email: .user.email}' data.json

# Add a field
jq '. + {processed: true}' data.json

# Delete a field
jq 'del(.password)' user.json
```

## Practical compound examples

```bash
# Extract emails from user array
jq -r '[.users[] | .email] | join(",")' data.json

# Sum a numeric field
jq '[.[].amount] | add' transactions.json

# Filter and reshape
jq '[.orders[] | select(.status == "pending") | {id, total: .amount}]' orders.json
```

## Useful flags

```bash
-r     raw output (no quotes on strings)
-c     compact output (one line)
-s     slurp (read entire input as one array)
-n     null input (start with null, useful with --argjson)
```
