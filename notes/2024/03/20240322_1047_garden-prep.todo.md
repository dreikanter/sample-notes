# Garden prep tasks for spring

The last average frost date here is around April 12. Need to get organized before then.

**Soil and beds**

- [ ] Turn the two raised beds in the back corner; add compost from the bin
- [ ] Test soil pH in the vegetable bed — last reading was 6.1, aiming for 6.5
- [ ] Order a bag of lime if pH is still low
- [ ] Pull the dead Jerusalem artichoke stalks from the far bed

**Seeds and starts**

- [ ] Start tomatoes and peppers indoors by March 25 (8 weeks before transplant)
- [ ] Order replacement seed packets: romano beans, Armenian cucumber, shiso
- [ ] Label seed trays properly this time — last year's mystery seedlings were a problem

**Infrastructure**

- [ ] Fix the drip line on the east bed; two emitters are clogged
- [ ] Find the row-cover hoops — think they're behind the garage
- [ ] Patch the cold frame lid where the hinge cracked

**Reference**

Planting calendar for this region: [Old Farmer's Almanac frost dates](https://www.almanac.com/gardening/frostdates). Worth cross-checking against local extension office data since microclimates vary a lot within a few miles.
