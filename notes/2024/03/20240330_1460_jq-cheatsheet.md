# jq cheatsheet

`jq` for JSON processing from the command line. I look up the same patterns repeatedly.

## Basic selection

```bash
echo '{"name": "Alice", "age": 30}' | jq '.name'
# "Alice"

echo '{"user": {"email": "a@b.com"}}' | jq '.user.email'
# "a@b.com"

# Array index
echo '[10,20,30]' | jq '.[1]'
# 20

# Slice
echo '[1,2,3,4,5]' | jq '.[2:4]'
# [3,4]
```

## Array operations

```bash
# All elements
jq '.[]'

# Length
jq 'length'

# Map
jq '[.[] | .name]'
# or
jq '[.[] | select(.active)] | map(.name)'

# Filter
jq '.[] | select(.age > 25)'

# Sort
jq 'sort_by(.name)'
jq 'sort_by(.score) | reverse'

# Unique
jq '[.[].tag] | unique'
```

## Building output

```bash
# Construct new object
jq '{id: .id, fullname: (.first + " " + .last)}'

# Multiple outputs → array
jq '[.users[] | {name: .name, active: .active}]'

# Raw string output (no quotes)
jq -r '.name'

# CSV
jq -r '.[] | [.name, .age] | @csv'
```

## Useful flags

```bash
jq -r    # raw output (no JSON quotes)
jq -c    # compact (single line)
jq -s    # slurp (read multiple JSONs into array)
jq -n    # null input (for building from scratch)
jq -e    # exit 1 if result is false/null
```

## Practical one-liners

```bash
# Pretty-print a file
jq '.' data.json

# Extract specific field from API response
curl -s api/endpoint | jq -r '.data[].name'

# Count array elements
jq '.items | length' response.json
```
