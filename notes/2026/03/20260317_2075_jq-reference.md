# jq reference

`jq` is indispensable for JSON manipulation on the command line. I reach for it constantly and forget the syntax constantly.

## Basic selection

```bash
echo '{"name":"Alice","age":30}' | jq '.name'
# "Alice"

jq '.users[0]' data.json          # first element of users array
jq '.users[].email' data.json     # all emails from users array
jq '.users | length' data.json    # count users
```

## Filters and transforms

```bash
# Select objects matching a condition
jq '.users[] | select(.active == true)' data.json

# Map over array
jq '.users | map(.email)' data.json

# Map and filter combined
jq '[.users[] | select(.age > 18) | .name]' data.json

# Add a field
jq '.users[] | . + {role: "member"}' data.json
```

## Useful built-ins

```bash
jq 'keys'                    # keys of an object
jq 'values'                  # values of an object
jq 'to_entries'              # [{key:k, value:v}, ...]
jq 'from_entries'            # reverse of to_entries
jq 'has("field")'            # test if key exists
jq 'type'                    # "array", "object", "string", etc.
jq 'sort_by(.name)'          # sort array by field
jq 'group_by(.type)'         # group array by field value
jq 'unique_by(.id)'          # deduplicate by field
```

## Output options

```bash
jq -r '.name'      # raw output (no quotes around strings)
jq -c '.'          # compact (single line) output
jq -s '.'          # slurp: read all inputs into array
jq -n '...'        # null input (no input file needed)
```

## Practical one-liners

```bash
# Pretty-print any JSON
cat ugly.json | jq '.'

# Extract all unique values of a field
jq -r '[.[].status] | unique[]' data.json

# Count by value
jq 'group_by(.status) | map({(.[0].status): length}) | add' data.json
```
