# HTMX patterns for Go backends

Notes from building the SQLite web app (see [[20260408_2091]]). HTMX is working well; here are the patterns I'm using.

## Basic pattern: swap content on click

```html
<button hx-get="/pages/42/edit"
        hx-target="#page-row-42"
        hx-swap="outerHTML">
  Edit
</button>
<tr id="page-row-42">...</tr>
```

The server returns an HTML fragment, not a full page. The fragment replaces the target element.

## Form submission with inline response

```html
<form hx-post="/pages/42"
      hx-target="#page-row-42"
      hx-swap="outerHTML">
  <input name="title" value="Current Title">
  <button type="submit">Save</button>
  <button hx-get="/pages/42/view" hx-target="#page-row-42" hx-swap="outerHTML">
    Cancel
  </button>
</form>
```

On submit, the server handles the update and returns the view fragment (not the form).

## Server-side Go handler pattern

```go
func (h *Handler) EditPage(w http.ResponseWriter, r *http.Request) {
    id := chi.URLParam(r, "id")
    page, _ := h.store.GetPage(id)
    // Return just the edit form fragment
    h.templates.ExecuteTemplate(w, "page-edit-form.html", page)
}

func (h *Handler) UpdatePage(w http.ResponseWriter, r *http.Request) {
    // ... parse form, update store ...
    page, _ := h.store.GetPage(id)
    // Return the view fragment (not the form)
    h.templates.ExecuteTemplate(w, "page-row.html", page)
}
```

## Detecting HTMX requests

```go
if r.Header.Get("HX-Request") == "true" {
    // return fragment
} else {
    // return full page
}
```

Useful for making URLs work both with and without JavaScript.

## Out-of-band swaps

```html
<div hx-swap-oob="true" id="page-count">42 pages</div>
```

Update multiple targets in a single response. The element with `hx-swap-oob` swaps with its matching ID on the page regardless of the primary target.
