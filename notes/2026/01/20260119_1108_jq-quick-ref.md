# jq quick reference

Official docs: https://stedolan.github.io/jq/manual/

## Basics

```sh
# Pretty-print
cat data.json | jq '.'

# Extract a field
jq '.name' data.json

# Extract nested field
jq '.user.email' data.json

# Array index
jq '.[2]' data.json

# All array elements
jq '.[]' data.json
```

## Filtering and selecting

```sh
# Filter array by condition
jq '.[] | select(.status == "active")' data.json

# Multiple conditions
jq '.[] | select(.age > 30 and .country == "DE")' data.json

# Has key
jq '.[] | select(has("metadata"))' data.json
```

## Transforming

```sh
# Build new object
jq '.[] | {id: .id, label: .name}' data.json

# Add fields
jq '. + {generated: true}' data.json

# Map over array
jq '[.[] | .price * 1.2]' data.json

# Flatten one level
jq '[.[] | .[]]' data.json
```

## String operations

```sh
# String interpolation
jq '.[] | "User: \(.name)"' data.json

# Split and join
jq '.tags | join(", ")' data.json

# Test regex
jq '.[] | select(.email | test("@example\\.com"))' data.json
```

## Useful flags

| Flag | Effect |
|------|--------|
| `-r` | Raw output (no quotes on strings) |
| `-c` | Compact output (one line) |
| `-e` | Exit 1 if output is null/false |
| `--arg k v` | Bind shell variable into jq |
| `--slurp` | Read all input into one array |

## With `--arg`

```sh
jq --arg env "production" '.[] | select(.env == $env)' data.json
```

## Reduce

```sh
# Sum a field
jq '[.[] | .amount] | add' data.json

# Count matching
jq '[.[] | select(.active)] | length' data.json
```
