# TypeScript utility types — reference

Documenting the utility types I reach for most often. Full reference: https://www.typescriptlang.org/docs/handbook/utility-types.html

## Partial and Required

```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

type PartialUser = Partial<User>;
// { id?: number; name?: string; email?: string; }

type RequiredUser = Required<PartialUser>;
// Back to all required
```

## Pick and Omit

```typescript
type UserPreview = Pick<User, 'id' | 'name'>;
// { id: number; name: string; }

type UserWithoutEmail = Omit<User, 'email'>;
// { id: number; name: string; }
```

## Record

```typescript
type StatusMap = Record<string, boolean>;
type UserById = Record<number, User>;
```

## Exclude and Extract

```typescript
type Status = 'active' | 'inactive' | 'pending' | 'deleted';

type LiveStatus = Exclude<Status, 'deleted' | 'inactive'>;
// 'active' | 'pending'

type ArchiveStatus = Extract<Status, 'inactive' | 'deleted'>;
// 'inactive' | 'deleted'
```

## ReturnType and Parameters

```typescript
function fetchUser(id: number): Promise<User> { ... }

type FetchUserReturn = ReturnType<typeof fetchUser>;
// Promise<User>

type FetchUserParams = Parameters<typeof fetchUser>;
// [id: number]
```

## NonNullable

```typescript
type MaybeUser = User | null | undefined;
type DefiniteUser = NonNullable<MaybeUser>;
// User
```

Most underused in my experience: `Awaited<T>` for unwrapping Promise types recursively. Extremely handy when dealing with async utility functions.
