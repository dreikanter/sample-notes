# Sed quick reference

A working cheatsheet for `sed` patterns I keep forgetting and having to look up. Tested on GNU sed 4.8 (Linux) — BSD sed on macOS differs in a few places noted below.

**In-place editing**

```
sed -i 's/old/new/g' file.txt          # GNU
sed -i '' 's/old/new/g' file.txt       # BSD (macOS)
```

**Delete lines matching a pattern**

```
sed '/^#/d' file.txt                   # delete comment lines
sed '/^\s*$/d' file.txt                # delete blank lines
```

**Print specific line numbers**

```
sed -n '5p' file.txt                   # print line 5
sed -n '5,10p' file.txt               # print lines 5–10
```

**Address ranges**

```
sed '2,4s/foo/bar/' file.txt           # substitute only on lines 2–4
sed '/start/,/end/d' file.txt          # delete between markers (inclusive)
```

**Append and insert**

```
sed '3a\new line here' file.txt        # append after line 3
sed '3i\new line here' file.txt        # insert before line 3
```

**Multiple expressions**

```
sed -e 's/a/A/' -e 's/b/B/' file.txt
```

**Strip trailing whitespace**

```
sed 's/[[:space:]]*$//' file.txt
```

BSD note: backreferences with `\1` work but extended regex requires `-E` flag on macOS, same as `-r` on GNU sed.

For anything more complex than a few substitutions, `awk` is usually cleaner. The GNU sed manual is comprehensive: [https://www.gnu.org/software/sed/manual/sed.html](https://www.gnu.org/software/sed/manual/sed.html)
