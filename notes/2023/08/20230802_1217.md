# Rsync cheatsheet

Quick reference for rsync flags I keep forgetting. Based on the man page at https://linux.die.net/man/1/rsync and practical experience.

**Basic syntax**

```
rsync [options] source destination
```

Local to remote:
```
rsync -avz /local/path/ user@host:/remote/path/
```

Remote to local:
```
rsync -avz user@host:/remote/path/ /local/path/
```

**Flag breakdown**

- `-a` — archive mode: recursive, preserves symlinks, permissions, timestamps, owner, group
- `-v` — verbose
- `-z` — compress during transfer
- `-n` / `--dry-run` — simulate without writing
- `--delete` — remove destination files not in source (careful!)
- `--exclude='*.log'` — exclude pattern
- `--progress` — show per-file progress
- `-e ssh` — explicit SSH transport (usually implied)
- `--checksum` — compare by checksum not timestamp+size, slower but reliable
- `--bwlimit=1000` — throttle to 1 MB/s

**Trailing slash gotcha**

`rsync src/ dest/` copies contents of src into dest. `rsync src dest/` copies src itself as a subdirectory. I burn myself on this every few months.

**Partial transfers**

`--partial` keeps partially transferred files on interruption. `--partial-dir=.rsync-partial` isolates them cleanly so you don't end up with half-written originals.

**Example: nightly backup**

```bash
rsync -avz --delete --exclude='.DS_Store' \
  /home/user/documents/ backup@nas:/volume1/documents/
```
