# tmux quick reference

Working notes from getting tmux muscle memory established. I keep forgetting the less common bindings, so recording them here.

Default prefix is `Ctrl-b`. I've rebound it to `Ctrl-a` in `.tmux.conf` since I rarely use the Bash line-start shortcut and `Ctrl-a` is easier to reach.

## Sessions

| Action | Keys |
|---|---|
| New session | `tmux new -s name` |
| List sessions | `tmux ls` or `prefix $` |
| Rename session | `prefix $` |
| Detach | `prefix d` |
| Switch to next | `prefix )` |
| Kill session | `tmux kill-session -t name` |

## Windows

| Action | Keys |
|---|---|
| New window | `prefix c` |
| Rename window | `prefix ,` |
| Next/prev | `prefix n` / `prefix p` |
| Go to window N | `prefix N` |
| Close window | `prefix &` |

## Panes

| Action | Keys |
|---|---|
| Split horizontal | `prefix "` |
| Split vertical | `prefix %` |
| Navigate | `prefix` + arrow |
| Resize | `prefix Ctrl` + arrow |
| Zoom pane | `prefix z` |
| Close pane | `prefix x` |
| Convert pane to window | `prefix !` |

## Copy mode

Enter with `prefix [`. Navigate with vim keys after adding `setw -g mode-keys vi` to config. `v` to begin selection, `y` to yank to system clipboard (requires `xclip` or `pbcopy` bridge).

## Useful config lines

```
set -g mouse on
set -g history-limit 50000
set -sg escape-time 0
```
