# Rust — building a small CLI tool

Following through on the intention from [[20231001_1281]]: writing a small Rust project to get beyond reading and into doing. The project: a command-line tool that reads a directory of text files and outputs a word frequency report.

Simple enough to complete, complex enough to use ownership and file I/O.

## What I've learned building this

**Reading files:**

```rust
use std::fs;
use std::io::{self, BufRead};

fn read_lines(path: &str) -> io::Result<Vec<String>> {
    let file = fs::File::open(path)?;
    let reader = io::BufReader::new(file);
    reader.lines().collect()
}
```

The `?` operator propagates errors up the call stack — much cleaner than nested match statements.

**Counting words:**

```rust
use std::collections::HashMap;

fn count_words(text: &str) -> HashMap<String, usize> {
    let mut counts = HashMap::new();
    for word in text.split_whitespace() {
        let word = word.to_lowercase();
        let word = word.trim_matches(|c: char| !c.is_alphabetic());
        if !word.is_empty() {
            *counts.entry(word.to_string()).or_insert(0) += 1;
        }
    }
    counts
}
```

The `.entry().or_insert()` pattern is idiomatic Rust for incrementing map values.

**Sorting by frequency:**

```rust
let mut sorted: Vec<(&String, &usize)> = counts.iter().collect();
sorted.sort_by(|a, b| b.1.cmp(a.1));
```

**The borrow checker fight:**

Spent 20 minutes on a borrowing error that came from trying to both mutate and read a HashMap in the same scope. The fix was to collect into a Vec before sorting — can't sort a HashMap in place anyway.
