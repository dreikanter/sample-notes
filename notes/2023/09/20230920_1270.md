# Security audit prep — checklist notes

The quarterly security review is in two weeks. Getting organized.

Reference: OWASP Top 10 https://owasp.org/www-project-top-ten/

## Authentication and session management

- [ ] All endpoints requiring auth are behind the new auth middleware [[20230914_1264]]
- [ ] Session tokens are rotated after privilege escalation (login, role change)
- [ ] Token expiry is enforced server-side (not just client-side)
- [ ] Failed login attempts are rate-limited
- [ ] Password reset flow uses time-limited tokens, not persistent links

## Input validation

- [ ] All database queries use parameterized statements (no string interpolation)
- [ ] File upload endpoints validate MIME type and size server-side
- [ ] Inputs are validated at the API boundary, not just the UI
- [ ] XML inputs go through a restricted parser (no XXE)

## Output encoding

- [ ] User-controlled content is escaped before rendering in HTML contexts
- [ ] JSON API responses have correct content-type headers
- [ ] CSP headers are set and not permissive (no `unsafe-inline` without nonce)

## Dependencies

- [ ] Run `npm audit` and address critical/high findings
- [ ] Check for packages with known CVEs in the current lockfile
- [ ] Review third-party packages added in last quarter

## Infrastructure

- [ ] S3 buckets with user uploads are not publicly accessible
- [ ] Database instances are not accessible from the public internet
- [ ] Secrets are in AWS Secrets Manager, not environment variables committed to the repo
- [ ] VPC security groups reviewed — are any ports open that shouldn't be?

## Logs and monitoring

- [ ] Audit logs exist for all authentication events
- [ ] Logs do not contain plaintext tokens or passwords
- [ ] Alert exists for unusual authentication failure patterns
