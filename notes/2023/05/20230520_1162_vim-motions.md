# Vim motions — the ones that changed how I work

Not a beginner's guide. These are the specific motions that, once internalised, made me significantly faster.

**Text objects**

The most underused feature in Vim. `ci"` changes inside quotes. `ca(` changes around parentheses (including delimiters). `dit` deletes inside HTML tag. `vip` selects the current paragraph.

The pattern: `{operator}{a|i}{delimiter}`. Works with `d`, `c`, `y`, `v`.

**`f` and `t`**

`ft` jumps to the next 't' on the line. `Ft` jumps backward. `;` repeats, `,` reverses. `tt` jumps to just before the next 't'. Once you have this, reaching for `$` and arrow keys feels archaic.

**`%`**

Jump between matching brackets, braces, parens. Also works with `#if / #endif` in C.

**`*` and `#`**

Search for word under cursor forward/backward. Combined with `n/N` this is faster than `/word`.

**Marks**

`ma` sets mark a. `'a` jumps to mark a. Marks persist across sessions if in uppercase: `'A`.

**Recording macros**

`qa` starts recording to register a. `q` stops. `@a` plays back. `100@a` repeats 100 times. The first macro I ever found useful was for reformatting a CSV column.

**`:g` command**

`:g/pattern/d` deletes all lines matching pattern. `:g/TODO/t$` copies all TODO lines to the end of file. Global command is extremely powerful and extremely underused.
