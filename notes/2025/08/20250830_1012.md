# Docker compose, small things I keep forgetting

Collected from actually hitting each one at least twice.

- `depends_on` without a healthcheck only waits for the container to
  *start*, not for the service inside to be ready. For real ordering,
  add `condition: service_healthy` and define the healthcheck.
- `env_file` entries are loaded in order; later files override
  earlier ones. Useful for layering a `.env.local` on top of the
  committed defaults.
- `restart: unless-stopped` is almost always what I want on a long-
  running dev stack. `always` will fight you after a manual stop.
- Volume names are namespaced to the project. `docker compose down -v`
  drops them; plain `down` keeps them.
- Bind-mounted source directories override anything `COPY`ed in the
  Dockerfile for that path. Surprising the first time.

Docs: <https://docs.docker.com/compose/>
