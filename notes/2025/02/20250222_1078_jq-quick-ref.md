# jq quick-ref

Personal cheatsheet for `jq` — I keep forgetting the filter syntax and want one place to check.

Source: [jq manual](https://jqlang.github.io/jq/manual/)

---

## Basic selection

```
.key              # top-level key
.key.nested       # nested
.["key with space"]
.[0]              # array index
.[-1]             # last element
.[]               # iterate all elements
```

## Pipe and collect

```
.items[] | .name           # each name from array
[.items[] | .name]         # collect into array
{name: .name, id: .id}     # construct object
```

## Conditionals

```
if .score > 5 then "high" else "low" end
.value // "default"         # alternative operator
```

## select and map

```
.[] | select(.active == true)
map(. * 2)
map(select(.type == "A"))
```

## String interpolation

```
"\(.name) has \(.count) items"
```

## Reduce

```
reduce .[] as $x (0; . + $x)
```

## Useful builtins

```
length
keys, values
has("field")
in({"a":1})
type            # "object", "array", "string", "number", "boolean", "null"
to_entries | from_entries
with_entries(select(.value != null))
ascii_downcase, ascii_upcase
split(",") | join(" ")
env.HOME        # environment variable
input, inputs   # multiple input files
```

## Slurp mode

```
jq -s '.[0] + .[1]' a.json b.json    # merge two files
```

## Raw output

```
jq -r '.name'    # no quotes around strings
jq -c '.'        # compact output
```

## Common one-liners I actually use

```bash
# Pretty-print
curl -s https://api.example.com/data | jq '.'

# Extract list of names
jq -r '.[].name' data.json

# Filter by field value
jq '.[] | select(.status == "active")' records.json

# Count array elements
jq '.items | length' response.json

# Merge all objects in array
jq 'reduce .[] as $x ({}; . + $x)' objects.json
```
