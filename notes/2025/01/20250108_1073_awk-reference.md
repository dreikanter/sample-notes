# awk one-liners reference

I reach for awk when `cut` isn't enough and I don't want to pull in Python for something simple. These are patterns I've used in the past year, written down so I stop re-deriving them.

## Field selection

```
awk '{print $2, $4}'          # fields 2 and 4
awk -F: '{print $1}'          # colon-delimited, first field
awk 'NF > 3 {print $NF}'     # last field, but only if >3 fields exist
```

## Filtering and conditions

```
awk '/ERROR/ {print}'
awk '$3 > 500 {print $0}'
awk 'NR >= 10 && NR <= 20'    # lines 10 through 20
awk '!seen[$0]++'             # deduplicate (order-preserving)
```

## Arithmetic and aggregation

```
awk '{sum += $5} END {print sum}'
awk '{sum += $5; n++} END {print sum/n}'  # mean of field 5
```

## Multi-file and BEGIN/END

```awk
BEGIN {FS=","; OFS="\t"}
FNR == 1 {next}               # skip header in each file
{gsub(/\r/, ""); print}       # strip Windows line endings
END {print "total:", NR, "records"}
```

## Practical log example

Sum response times from an nginx access log where field 10 is request duration:

```
awk '$9 == 200 {sum += $10; n++} END {printf "avg: %.2fms over %d reqs\n", sum/n, n}' access.log
```
