# Bash one-liners for log parsing

Quick reference built up while debugging a slow cron job. The job was writing to a rotating log file and I needed to extract timing data without loading the whole file into an editor.

Print lines between two timestamps:

```bash
awk '/2025-05-19 14:00/,/2025-05-19 15:00/' /var/log/app.log
```

Count occurrences of each HTTP status code in an nginx log:

```bash
awk '{print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -rn
```

Find the top 10 slowest requests (last field is response time in ms):

```bash
awk '{print $NF, $0}' access.log | sort -rn | head -10 | cut -d' ' -f2-
```

Strip ANSI color codes from a log file so it's grep-able:

```bash
sed 's/\x1b\[[0-9;]*m//g' colored.log > plain.log
```

Watch a log in real time, highlighting lines that contain ERROR:

```bash
tail -f app.log | grep --color=always -E 'ERROR|$'
```

The `--color=always` flag keeps coloring on even though stdout is being piped. The `|$` part of the regex matches every line so nothing is filtered out — only the ERROR lines get highlighted.

More patterns documented at https://www.loggly.com/ultimate-guide/analyzing-linux-logs-with-the-shell/

The awk timestamp range trick is underused. It's cleaner than piping through grep twice and doesn't require the timestamps to be at the start of the line.
