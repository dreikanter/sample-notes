# Home network audit tasks

Working through a full audit of the home network after noticing some unexpected devices in the DHCP lease table. Logging tasks here so nothing gets missed.

- [x] Export DHCP lease table from router admin panel
- [x] Cross-reference known MAC addresses against device list
- [ ] Identify the two unknown MAC addresses (192.168.1.47, 192.168.1.103)
- [ ] Change WiFi password on 2.4GHz band — hasn't been rotated in 2 years
- [ ] Enable WPA3 on router if firmware supports it
- [ ] Set VLAN for IoT devices (thermostat, printer, smart bulbs) separate from main LAN
- [ ] Disable UPnP — rarely needed and a known attack surface
- [ ] Review port forwarding rules — there's an old Plex forward still active
- [ ] Check firmware version on router — currently 3.0.0.4.384, latest is 3.0.0.4.388
- [ ] Configure DNS over HTTPS or DNS over TLS on router
- [ ] Set up logging to NAS so traffic data persists past router memory

Reference for home network hardening: https://www.cisa.gov/sites/default/files/publications/HomeRouterSecurity2023.pdf

After VLAN segmentation, the smart bulbs lose nothing functionally but the main network is no longer reachable from a compromised bulb. The unknown devices are the most pressing item — they could be neighbors accidentally connecting or something more concerning.
