# AWK one-liners I actually use

AWK is a program I use infrequently enough that I always have to look things up. Collecting the patterns here.

## Basic structure

```
awk 'pattern { action }' file
```

Pattern and action are both optional. Default pattern matches everything; default action is `{ print }`.

Built-in variables:
- `NR` — current record (line) number
- `NF` — number of fields in current record
- `$0` — entire current line
- `$1..$NF` — individual fields (space-delimited by default)
- `FS` — field separator (set with `-F`)
- `OFS` — output field separator

## One-liners

```bash
# Print specific column
awk '{ print $3 }' file.tsv

# CSV with comma separator
awk -F, '{ print $1, $3 }' file.csv

# Print lines matching pattern
awk '/error/' app.log

# Print lines where field 5 > 100
awk '$5 > 100' data.txt

# Sum a column
awk '{ sum += $2 } END { print sum }' data.txt

# Print line count (like wc -l but can filter)
awk 'END { print NR }' file.txt

# Print unique values of column 1
awk '!seen[$1]++' file.txt

# Print lines between markers
awk '/START/,/END/' file.txt

# Remove duplicate blank lines
awk 'NF > 0 || prev > 0 { print; prev = NF }' file.txt

# Tab-delimited output
awk -F, 'BEGIN { OFS="\t" } { print $1, $2, $3 }' file.csv
```

## When to use awk vs. alternatives

- AWK: field-based text processing, quick column operations, streaming aggregation
- `cut`: simpler column extraction with single delimiter
- `jq`: JSON (always prefer jq for JSON)
- Python/perl: complex logic, multi-file joins

Reference: [The AWK Programming Language](https://awk.dev/) (the original Aho, Weinberger, Kernighan book).
