# jq quick reference

`jq` is a command-line JSON processor. Invaluable for working with API responses and config files in the terminal.

## Basic usage

```bash
# Pretty print
curl -s api.example.com/data | jq .

# Access a field
jq '.name'
jq '.user.email'

# Access array element
jq '.[0]'
jq '.items[2]'

# Iterate array
jq '.items[]'

# Pipe (chain transformations)
jq '.items[] | .name'
```

## Filters and selection

```bash
# Select by condition
jq '.items[] | select(.active == true)'
jq '.items[] | select(.score > 90)'

# Multiple conditions
jq '.[] | select(.type == "error" and .severity > 2)'

# Map
jq '.items | map(.name)'
jq '.items | map(select(.active))'
```

## Output construction

```bash
# Build new object
jq '{name: .user.name, email: .user.email}'

# Build from array
jq '[.items[] | {id: .id, name: .name}]'

# String interpolation
jq '"Hello, \(.name)"'
```

## Useful built-ins

```bash
jq 'keys'               # object keys as array
jq 'values'             # object values as array
jq 'length'             # array length or string length
jq 'has("field")'       # check key exists
jq 'type'               # "object", "array", "string", etc.
jq 'to_entries'         # [{key:..., value:...}]
jq 'from_entries'       # reverse of to_entries

# Sort and unique
jq 'sort_by(.name)'
jq '[.[].tag] | unique | sort'
```

## Raw output

```bash
jq -r '.name'           # raw string (no quotes)
jq -r '.items[] | .id'  # one per line
```
