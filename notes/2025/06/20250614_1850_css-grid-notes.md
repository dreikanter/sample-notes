# CSS Grid — the properties I always have to re-look up

Not a comprehensive guide — just the parts I use least often and therefore forget.

**Named grid areas**

```css
.layout {
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar content content"
    "footer footer footer";
  grid-template-rows: auto 1fr auto;
  grid-template-columns: 200px 1fr 1fr;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
```

More readable than column/row spans for complex layouts.

**Subgrid**

Now well-supported (Chrome 117+, Firefox 71+, Safari 16+):

```css
.parent {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
}

.child {
  grid-column: span 2;
  display: grid;
  grid-template-columns: subgrid; /* inherits parent's tracks */
}
```

Solves the "align items inside cards to their siblings in other cards" problem elegantly.

**auto-fill vs auto-fit**

```css
/* auto-fill: creates as many tracks as fit, even if empty */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

/* auto-fit: collapses empty tracks, letting items expand */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

For responsive grids where items should expand to fill available space, `auto-fit` is usually what you want.

**Alignment shorthand**

`place-items` is shorthand for `align-items` + `justify-items`. `place-content` is shorthand for `align-content` + `justify-content`.
