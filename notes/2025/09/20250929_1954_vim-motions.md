# Vim motions reference

I've been using a vim plugin in VS Code for two years and still catch myself reaching for the mouse. Writing down the motions I want to internalize.

## Movement

```
h j k l     left, down, up, right
w / W       next word start (word / WORD)
b / B       prev word start
e / E       next word end
0           start of line (before any content)
^           first non-blank char of line
$           end of line
gg / G      first / last line of file
{n}G        go to line n
Ctrl+d/u    half-page down / up
%           jump to matching bracket/paren/brace
```

## Text objects

These combine with operators (d, c, y, v):

```
iw / aw     inner word / a word (includes surrounding space)
i" / a"     inside / around double quotes
i( / a(     inside / around parentheses
it / at     inside / around HTML tag
ip / ap     inner / a paragraph
```

Examples:
- `ciw` — change inner word (delete word, enter insert mode)
- `di"` — delete everything inside quotes
- `ya(` — yank everything including the parentheses

## Operators

```
d   delete (cuts to register)
c   change (delete + enter insert mode)
y   yank (copy)
>   indent
<   dedent
=   autoindent
```

## Search and replace

```
/pattern    search forward
?pattern    search backward
n / N       next / previous match
:%s/old/new/g   replace all in file
:s/old/new/g    replace in selection
```

## Registers

- `"ay` — yank to register a
- `"ap` — paste from register a
- `"+y` — yank to system clipboard

Reference: [Vim documentation](https://vimhelp.org/) and the built-in `:help` command.
