# CSS grid quick reference

Notes compiled while redesigning a sidebar layout. I always forget the shorthand properties.

## Defining a grid

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto 1fr auto;
  gap: 1rem 1.5rem; /* row-gap column-gap */
}
```

`fr` units distribute remaining space after fixed-size tracks are allocated.

## Placing items

```css
.item {
  grid-column: 1 / 3;      /* start / end (end is exclusive) */
  grid-row: 2 / span 2;    /* span keyword */
}
```

Negative line numbers count from the end: `grid-column: 1 / -1` spans the full row.

## Named areas

```css
.container {
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
```

## Auto-placement

`grid-auto-flow: dense` fills gaps left by larger items. Useful for masonry-like layouts but can affect visual order.

## Alignment

- `justify-items` / `align-items` — aligns items within their grid area
- `justify-content` / `align-content` — aligns the grid within the container when the grid is smaller than the container
- `place-items` — shorthand for align-items then justify-items

## Subgrid

Now supported in all modern browsers. Allows nested grids to align with the parent's tracks:

```css
.child {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: subgrid;
}
```

Full spec: [MDN CSS grid layout](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout)
